# 里程碑 1：骨架 + 数据层（models.py · blackboard.py · config）

状态：✅ 已实现并通过验证（ruff / mypy strict / 35 个 pytest 全绿）。

## Context

研究 Agent 系统（Agent Laboratory 风格）此前处于纯设计阶段——`Docs/architecture/` 下有完整架构文档，但无任何 Python 代码。架构文档 §9 的实现里程碑第 1 项是"骨架 + 数据层"：先把 Blackboard 数据模型、版本化/CAS/持久化、以及集中配置打底，且要求"可单测"。

这一层是整个系统的"单一事实来源"基础：后续沙箱、Agent、Solver、Orchestrator 都依赖这里定义的 Artifact schema 与 Blackboard 读写契约。

## 关键设计决策

1. **Artifact 信封 + 判别联合（discriminated union）**，不用泛型 `Artifact[T]`。单一具体 `Artifact`，`payload` 按 `kind` 字段判别。JSON 往返免注册表、异构存储统一一个 `TypeAdapter`、`model_validator` 集中校验 `namespace(id) == payload.kind`。
2. **集合类命名空间用 wrapper payload 包 list**（lit_review/runs/figures/reviews/decisions）→ 每命名空间恰好一个 payload 模型，CAS 对整集合版本化。
3. **配置用 pydantic-settings `BaseSettings`**：`.env` + `AR_` 前缀 + 嵌套覆盖（`__`）+ `SecretStr` 屏蔽 API key。
4. **`slice()` 本里程碑为确定性桩**（按 ref 顺序累加到 token 预算），真正相关性裁剪/摘要留到里程碑 6。

## 实现要点

- **CAS 语义**：版本权威在 Blackboard，`set` 忽略入参 `version`。新 id 要求 `expected_version==0`→赋 v1；既有 id `expected != latest` 抛 `VersionConflictError` 且 store 不变；旧版本全保留（回滚）。
- **快照**：`{"schema_version":1,"artifacts":{id:[v1,...]}}`，`model_dump(mode="json")`，原子写（`.tmp` + `os.replace`）。restore 缺文件→空；损坏 JSON→`BlackboardError`。
- **校验防线**：`extra="forbid"` + `frozen=True`；id 格式与命名空间校验；`score` 非有限值被拒（保 JSON 合法）。
- **订阅隔离**：坏订阅者 try/except 吞掉，不影响写入。
