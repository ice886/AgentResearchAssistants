# 2026-06-24

## SandboxManager

- 新增 Harness 层 `SandboxManager`，覆盖 Docker 沙箱起停、资源限额、断网、非 root、命令超时与 OOM 状态映射。
- 新增 fake Docker client 单测，验证生命周期、安全参数、并发槽、输出解析、超时 kill、OOM 与幂等清理，不依赖真实 Docker daemon。
- 扩展 `DockerConfig` 配置项，并更新 `.env.example`。
- 新增 `Docs/plan/2-SANDBOX_MANAGER.MD`、`Docs/guide/SANDBOX_MANAGER.MD`、`Docs/technical/SANDBOX_MANAGER.MD`。

## SandboxManager 影响范围

- `harness`：新增 sandbox 执行隔离模块与包入口导出。
- `config`：新增 Docker 用户、工作目录与 idle command 配置。
- `tests`：新增 sandbox 独立单测。
- `docs`：新增 plan、guide、technical 与 daily log 记录。

## RoleAgent + ToolRegistry

- 新增 Agent 层 `RoleAgent`，通过 `SDKAgentClient` Protocol 隔离真实 Claude Agent SDK，按角色注入模型、system prompt 与授权工具。
- 新增 Harness 工具层 `ToolRegistry`，支持工具注册、角色白名单、越权拒绝与最小权限工具查询。
- 新增 `run_code` 工具工厂，执行类工具只通过 `SandboxManager` 路由，并保证 teardown。
- 新增 fake SDK / fake sandbox 单测，不依赖真实 SDK、网络或 Docker daemon。
- 新增 `Docs/plan/3-ROLE_AGENT_TOOLREGISTRY.MD`、`Docs/guide/ROLE_AGENT_TOOLREGISTRY.MD`、`Docs/technical/ROLE_AGENT_TOOLREGISTRY.MD`。

## RoleAgent + ToolRegistry 影响范围

- `agents`：新增角色化 SDK subagent 封装与默认 prompt。
- `harness/tools`：新增工具契约与授权注册表。
- `sandbox`：作为 `run_code` 的唯一执行后端。
- `tests`：新增 RoleAgent 与 ToolRegistry 独立单测。
- `docs`：更新 plan、guide、technical、daily log 与 README。
